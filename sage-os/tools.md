# Tools and connectors

- Claude Code (Claude Pro) — coding agent
- Gemini (free) — Great Sage voice/chat brain
- GitHub — this repo
- FlutterFlow — TradieFlow builder
- Supabase — TradieFlow backend

## Also worth connecting for TradieFlow
- Gmail, Google Calendar — outreach drafts and scheduling
- Twilio — missed-call text-back feature
- FlutterFlow MCP — once on the Basic plan

## Rule
Start each new tool with read-only or "ask first" permissions. Only allow more
once it's proven trustworthy.
