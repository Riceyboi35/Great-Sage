# Great Sage OS

Dan's AI operating system, based on the context → tools → skills setup from
Remy Gaskell's Open Residency episode.

## Use it
Open this `sage-os` folder in Claude Code (or point the Great Sage TradieFlow
agent at it). `CLAUDE.md` loads automatically, so every session starts knowing
who Dan is, what TradieFlow is, and how he likes to work.

Test it: start a new session here and ask "who am I?"

## What's here
- `CLAUDE.md` — main instructions, always loaded (`AGENTS.md` for other agents)
- `context/` — about Dan, working style, TradieFlow, customers, offers, voice
- `memory.md` — corrections and preferences; grows over time
- `tools.md` — connected tools and the starter stack to add
- `.claude/skills/` — reusable processes (`lesson-summary`, `save-skill`)
